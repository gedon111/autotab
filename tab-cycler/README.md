# Tab Cycler

Every 2 minutes, switches to the next tab in the window and reloads it.

## Load it

1. Open `chrome://extensions` and turn on **Developer mode**.
2. Click **Load unpacked** and select this `tab-cycler` folder.

## Use it

1. Focus the window you want to cycle and click the Tab Cycler icon. A green **ON** badge appears.
2. Click the icon again to stop (the badge clears).

The first switch happens 2 minutes after you start. If the window is closed, cycling stops.
